# NextMin Documentation

Welcome to NextMin, the developer-first framework designed to turn TypeScript and JSON schemas into production-grade REST APIs, multi-database backends, and beautiful React admin panels with zero boilerplate.

Whether you are building an internal admin dashboard, a customer portal, or rapid prototyping a backend service, NextMin provides the server runtime and UI components you need.

## Core Packages

NextMin is split into modular packages so you can adopt either the backend engine, the React admin UI, or both together:

| Package | Role | Description |
| :--- | :--- | :--- |
| [`@airoom/nextmin-node`](/docs/nextmin-node) | Server Toolkit | Schema loader, Express REST router, multi-database adapter (SQLite, Postgres, Mongo), JWT/OTP auth, role-based access control (RBAC), and realtime events. |
| [`@airoom/nextmin-react`](/docs/nextmin-react) | Admin UI Toolkit | Headless React components, HeroUI data tables, auto-generated CRUD forms, Drawer record viewer, Tiptap rich-text editor, and Redux state provider. |
